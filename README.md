# Luxury Tiling & Bathroom Renovation

Responsive, dependency-free website demo using the 12 supplied images. All website source and assets are in `dist/`. Deploy on Vercel using the included configuration (output directory `dist`). No environment variables or form backend are needed. Quote requests use the supplied telephone number.

`dist/demo-config.js` contains the single shared `DEMO_START_AT` value. It is set once when this initial website is published. Do not reset on refresh or subsequent edits. Change it only when deliberately starting a new preview period.

Images are design inspiration, not verified completed business projects. Rating, address and phone are supplied by the client brief. The site contains no fabricated reviews or additional trade qualifications.

Image mapping: 4 hero; 9 main service; 1 detail/gallery; 11 and 10 transformation concept; 3, 5, 12 gallery; 6 bath feature; 7 craftsmanship illustration; 8 later FAQ detail; 2 final CTA.
